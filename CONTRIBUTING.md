# Contributing

ReviewFlow Lab welcomes focused reports and small pull requests related to PHP/Symfony pull-request analysis.

## Before starting

- Open or reference one issue with a clear outcome.
- Keep one issue to one observable result where possible.
- Record architecture, security, privacy, cost, or AI-provider decisions in an ADR.
- Do not add secrets, paid services, remote model providers, or new runtime dependencies without maintainer approval.

## Pull requests

- Never work directly on `main`.
- Include tests and explain any missing test coverage.
- Complete the pull-request template.
- Resolve deterministic failures before requesting AI review.
- Treat ReviewFlow findings as review support rather than a verdict.
- Do not accept risks on behalf of the maintainer.

External fork code is not executed automatically. The maintainer may inspect a fork pull request and explicitly allow a secretless test run.

## AI disclosure

State whether AI materially contributed to analysis, code, tests, or documentation. Do not list fictional team members or imply that AI accepted the increment.
